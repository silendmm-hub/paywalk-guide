# Бот клуба по подписке

Бот принимает оплату подписки через Точку, пускает в закрытую Telegram-группу и сам удаляет тех, кто перестал платить.

## Что видит человек

1. Пишет боту и видит, что входит в клуб и сколько стоит. Если он есть в старой группе, видит цену для своих.
2. Жмёт «Вступить», пишет почту для чека и получает ссылку на оплату картой.
3. Платит. Через несколько секунд бот присылает кнопку «Войти в клуб», и заявку в группу бот одобряет сам.
4. За день до списания бот напоминает, потом списывает деньги за следующий месяц.
5. Если деньги не списались, бот предупреждает и пробует раз в сутки. Через 3 дня (настраивается) удаляет из группы. Оплатит снова, пустят обратно.
6. Отменить подписку можно в боте, по /start. Доступ сохранится до конца оплаченного месяца.

Ссылкой на группу поделиться бесполезно: по ней можно только подать заявку, а одобряет бот только тех, кто оплатил.

Тебе в личку приходит: новый участник, отмена, неудачное списание, удаление.
Команды для тебя: `/stats` (сколько людей и денег), `/grant ID ДНЕЙ` (впустить бесплатно, например партнёра), `/revoke ID` (удалить).

## Что подготовить

**В Точке**
- Подключённый интернет-эквайринг: «Сервисы» → «Интернет-эквайринг». Для чеков выбери там партнёра по фискализации.
- JWT-ключ: «Интеграции и API» → создать ключ. Нужны разрешения на эквайринг (MakeAcquiringOperation, ReadAcquiringData), ReadCustomerData и ManageWebhookData. Там же будет `client_id`.

**В Telegram**
- Новый бот у @BotFather, из него токен.
- Новая группа (супергруппа) для клуба. Бот в ней админ с правами «Добавлять участников» и «Блокировать участников».
- Если нужна скидка старичкам, бота добавляют и в старую группу, можно без прав админа, просто участником.
- id групп и свой id можно узнать через @getmyid_bot или @username_to_id_bot.

**Сервер**
Любой VPS с Ubuntu, 1 ГБ памяти хватит (Timeweb, Aeza, Hostinger и т. п., 300–500 ₽ в месяц).
Бесплатный Cloudflare не подойдёт: у API Точки российский сертификат (НУЦ Минцифры), а Cloudflare ему не доверяет. Бот сам подгружает этот сертификат из папки `certs`.
Домен не обязателен: подойдёт адрес вида `1-2-3-4.sslip.io`, где 1.2.3.4 — IP сервера.

## Запуск

```bash
# на сервере
curl -fsSL https://get.docker.com | sh
git clone -b club-bot --single-branch https://github.com/silendmm-hub/paywalk-guide club-bot && cd club-bot
./setup.sh                             # спросит токены по одному и заполнит .env
docker compose run --rm bot python bot.py check           # покажет customerCode и merchantId, впиши их в .env
docker compose up -d --build
docker compose run --rm bot python bot.py setup-webhook   # подключит вебхук Точки
docker compose logs -f bot                                # посмотреть, что всё живое
```

Первую проверку лучше сделать на себе с ценой 10 ₽ (`PRICE=10`): оплатить, войти, отменить. Потом поставить нормальную цену и перезапустить: `docker compose up -d`.

## Как это устроено внутри

- Подписка в Точке создаётся «без графика» (`recurring: true`). Точка привязывает карту при первой оплате, а следующие списания запускает бот методом Charge Subscription. Так бот точно знает, прошло списание или нет.
- Вебхуки Точка шлёт только об успешных оплатах. Бот проверяет их подпись публичным ключом Точки.
- Если вебхук о первой оплате потерялся, человек жмёт «Я оплатил(а)», и бот спрашивает статус подписки у Точки.
- Если ответ на списание потерялся, а деньги пришли, доступ продлит вебхук. Двойного продления не будет.
- База лежит в `data/club.db` (SQLite). Её стоит иногда копировать себе.
- Тексты сообщений собраны в начале `bot.py`, в словаре `TEXTS`.

Тесты (без сети): `python -m unittest test_bot -v`
